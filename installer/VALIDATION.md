# Installer validation snapshot

On 2026-10-30 the native installer was built using Apple Swift 6.4.2/Xcode on Apple Silicon, targeting macOS 13. The release executable contains arm64 and x86_64 slices and links only Apple system frameworks and Swift runtime libraries. It does not require Node.js at installation time.

The Swift Testing suite contains **15 test functions with parameterized cases**. It exercises signed temporary app fixtures without launching them, compatible version/manifest parsing, source/signature tampering, rejection of a re-signed app with the wrong reviewed runtime checksum, explicit replacement and restoration, preservation of settings, running-app rejection, symlink path rejection, bounded ASAR reads, changed-destination refusal, rollback after a denied config write, and interrupted-restore journal recovery. All passed. Fixture copies and profiles are created in temporary directories; no real Yapper app or user profile is modified by these tests.

The standalone universal installer ZIP is checked after extraction with `codesign --verify --deep --strict`, `lipo`, and its CLI `--version`. Self-contained setup variants additionally use the same native validator to inspect their bundled client, checking its YapperCord version marker, reviewed bundle hash, relative bundle links, nested signatures, and client architecture. Independent bounded ASAR reads verify that the packed YapperCord and appearance scripts match both reviewed release hashes and the current source bytes. `scripts/verify-installer.mjs` reproduces those artifact checks and emits a report containing archive names and hashes rather than local source paths. All artifacts include the independently authored installer's MIT license and provenance boundary.

The built GUI opened and exposed its title, source and destination fields, replacement checkbox, profile disclosure and field, action buttons, and status text through native macOS accessibility. Before the planned source-chooser action, the automation reported that the user had changed the window; the check stopped without changing a field or invoking Install, Enable, Disable, or Restore. Source-chooser cancellation and the end-to-end GUI workflow remain untested. No screenshots containing local profile paths are published.

The Intel slice has not been run on Intel hardware, and the minimum macOS 13 deployment has not been tested on a macOS 13 machine. Native app signatures are ad-hoc; there is no Developer ID identity, notarization, privileged helper, or malware certification. Backup and rollback checks cover selected failure cases rather than every possible process crash, disk failure, or adversarial concurrent filesystem change.
