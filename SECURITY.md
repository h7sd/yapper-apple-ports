# Security reporting and verification

This unofficial port does not carry a malware-free certification. See [the scope and limitations of the review](docs/SECURITY-REVIEW.md) before granting native permissions.

Report client-side issues through this repository's Security reporting feature if available. If it is unavailable, open a minimal issue without credentials, private chat content, access tokens, exploit payloads, or other sensitive data. Issues in the Yapper service itself should be reported to Yapper through its own support/security channels.

Never attach signing keys, provisioning profiles, browser profiles, `settings.json`, or account/session data to an issue. A useful non-sensitive report includes the release name, operating-system version, steps to reproduce, and the relevant client source location.
