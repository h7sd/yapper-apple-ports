# Recovered upstream source

These four files preserve the application-owned JavaScript and manifest recovered from Yapper 1.1.0 in the supplied AppImage. The original manifest identifies the author as **Yapper** and the homepage as [yapper.website](https://www.yapper.website). The original icon is preserved separately as `../build/icon.png`.

Hashes are recorded in `../provenance.json`. `preload.js`, `games.js`, and the PNG icon remain unchanged in the macOS port. The port changes `main.js` and adds `mac-processes.js`; packaging and verification code are separate additions.
